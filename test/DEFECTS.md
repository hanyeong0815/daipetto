# 不具合・指摘管理表

単体テストで見つかった不具合（実装・設計書）と、その対応・再テストの記録。

- 区分: **実装** = プログラムの不具合、**設計書** = 設計書（docs/）と実装の不一致・記載漏れ
- 判断の基準: 設計書（docs/07 API設計書）を正とする。ただし、設計書の記述が古く実装が正しい（意図した変更が設計書に反映されていなかった）場合は設計書を修正した。
